# Five Night

A small Godot 4 project inspired by FNAF 1 gameplay.

Features:
- 12 AM to 6 AM night cycle
- Animated AI pressure inspired by FNAF 1
- Left and right office doors
- Camera view toggle
- Working phone-call text system (no audio)
- Power drain and fail state

How to run:
1. Open this folder in Godot 4.
2. Press F5 or use the Run button.
3. Use:
   - A = toggle left door
   - D = toggle right door
   - C = toggle camera
   - Q / E = cycle camera rooms

This is a simple starter project and is intentionally made with placeholder visuals so you can replace them later with your own art or assets.
